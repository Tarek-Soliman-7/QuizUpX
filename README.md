# 🎓 QuizUpX – University Quiz Backend API

QuizUpX is a simple backend project for managing university quizzes built with **ASP.NET Core Web API**.  
It provides endpoints that allow students to select a subject, log in using a university code & PIN, take a quiz, and receive their results.

---

## 🚀 Features

- Fetch available quiz subjects
- Student login using:
  - University Code
  - PIN
- Retrieve questions by subject
- Submit quiz answers
- Calculate score and store quiz attempts
- Database seeding for:
  - Students
  - Subjects
  - Questions

---

## 🧩 Tech Stack

- ASP.NET Core 8 Web API
- Entity Framework Core
- SQL Server
- Repository Pattern + Unit of Work
- DTO Mapping
- Async / Await
- JSON Serialization
